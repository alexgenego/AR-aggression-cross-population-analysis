# Analysis scripts

The final frozen release will contain the reproducible Python scripts used for:

1. Armenian single-locus models and FDR correction
2. Armenian joint seven-variant models and LASSO stability
3. Pairwise variant–variant interaction registry
4. Hadza–Datoga nine-variant models and genotype-by-population tests
5. Three-population AR/DRD4/HTR2A analysis
6. Variance, dispersion, and skewness analyses
7. Age sensitivity analyses
8. Power calculations
9. Final QC / output reconciliation

The scripts will expect restricted participant-level inputs from a local `data/` directory that is not committed to GitHub.
