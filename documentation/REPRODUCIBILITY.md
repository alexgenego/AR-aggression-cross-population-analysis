# Reproducibility workflow

## Public components

The repository is intended to expose:

- analysis code;
- genotype/phenotype coding rules;
- variant nomenclature and reference-sequence mapping;
- quality-control and reconciliation notes;
- non-identifying supporting tables and source data for publication figures.

## Restricted components

Participant-level Hadza and Datoga source files remain outside GitHub because the archival datasets contain provenance-sensitive and potentially identifying information.

## Frozen-release principle

The Zenodo DOI will be minted only after:

1. all analysis scripts reproduce the submitted summary tables;
2. the manuscript and Supporting Information are synchronized with the same output set;
3. repository paths and dependencies have been checked;
4. the final GitHub release has been tagged.
