# Restricted input data

Do not place participant-level source files in the public GitHub repository.

In particular, the archival Hadza/Datoga working files may contain names, field identifiers, linkage information, or other provenance-sensitive variables.

For local reproduction, create a private/local `data/` directory and place approved input files there. The `data/` directory should remain excluded from version control.

Publicly shareable materials belong in `supporting_information/`.
