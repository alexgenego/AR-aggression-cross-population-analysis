# Supporting information

The journal Supporting Information is maintained as a separate submission package and is **not** the source of participant-level data for this public repository.

Publicly shareable components include:

- detailed analytical tables S1-S9;
- genotype/phenotype coding and variant-nomenclature dictionary S10;
- non-identifying figure source data generated by the analysis scripts.

The submission workbooks contain the repository URL:

https://github.com/alexgenego/AR-aggression-cross-population-analysis

A Zenodo DOI will be inserted into the final journal Supporting Information after the frozen repository release is prepared.

Restricted participant-level source data, names, field identifiers, and linkage tables must never be placed in this directory.
